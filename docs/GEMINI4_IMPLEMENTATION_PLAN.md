# Gemini 4 视觉与验证改造任务

基线为 `90278c8`。实现代码由现有 agy 中的 Gemini 4 Argon (High) 生成；本地应用补丁、审查并运行验证。模型当前公开的最高思考档为 High，不声明不存在的额外预算参数。

## 需要交付的修改

1. **任务词表与名称绑定**：沿用现有 YOLOE，保留基础类别，为当前指令追加有界目标、空间地标和转弯地标词；词表和 text embeddings 缓存，四视角一致，不新增检测轮次。补齐眼科视力表等已知漏词，复合对象不能被宽松映射成另一个目标。
2. **二维候选独立保存**：深度不足、点云不足或建图过滤不能抹掉已识别的当前二维候选。候选有当前观测、视角、原图 bbox、mask、类别、置信度和几何可用状态；未知距离为 null。原三维实体接口保持可用。
3. **跨视角实体关联**：候选必须相对同一原始点集独立评分，再选择唯一匹配；不在评分中依次扣除点云。歧义对象保持分离，已有实体 ID 不重排。
4. **高清候选复核**：在原有模型请求中附有界原图候选裁剪、编号及上下文。模型选择当前候选 ID，测距始终使用其原图区域；不把 crop 内坐标直接绑定原图深度。转弯地标也使用自己的独立候选。
5. **位置关系**：分开主目标、空间参照物、第二个 between 物体与门框。明确关系参考坐标系；缺帧、深度、身份或坐标系时为 unknown。保留 near、between、门槛和楼梯现有几何门禁，不以视觉描述虚构三维坐标。
6. **真实关键事件**：由执行账本派生指令转弯、路径对齐、转后首次离开、受阻、实际升降、平台和恢复事件。显式区分执行步、控制器步和前后观测编号；模型计划不产生执行事实。
7. **事件图像**：验证器独立保存和选择事件前后图，带明确图文编号、视角和历史标记，保留 planner 旧图片接口。历史图片不授权当前目标深度或独立新视角。
8. **验证器证据输入**：关键事件摘要加完整有界账本，突出动作所属条件和用途。恢复及被撤销轨迹仅作诊断，不能证明当前合法路线完成；保持真实引用和已有严格 STOP 校验。
9. **验证器专用 BEV**：固定地图方向，真实轨迹的步骤箭头、原地朝向、恢复与撤销配色，按实际高度分面或附高度摘要。仅绘已观测地图，不读取评测目标或参考轨迹；planner 原 heading-up 图保持不变。

## 实施顺序

- 感知基础：任务词表、二维候选、稳定关联及轻量测试。
- 证据基础：关键事件、图像选择和专用 BEV 纯 CPU 模块。
- 生产集成：候选选择/裁剪、位置关系、地标绑定及真实 verifier 请求内容。
- 验证与修补：原有回归、生产链新增检查、同输入失败片段和成功对照。

## 不变量

- 不改旧实验目录，不停止旧实验；原120批次和51个已完成结果保留。
- 不升级 Habitat/Python/PyTorch，不自动下载新识别模型；本轮优先利用现有 YOLOE。
- 子任务拆分保持关闭；串行使用 GPU，只测有界易错片段。
- 不放宽有效深度、目标绑定、独立视角、路线执行、门槛和楼梯平台检查。
- 旧观测或未知测距不能 STOP；协议重试不能伪造动作和新观测。
- 每个阶段保持可审查的源码与测试。模型输出经审查和测试后才提交，不把模型自称完成当作验证。
- GitHub 保持 Private；代码任务完成后自动提交、推送任务分支并创建 Draft PR，不合并 main。

## 验收

生产函数中的任务词→检测→候选→原图 mask/depth 绑定必须接通；无三维点仍保留二维身份候选，但不能生成距离。候选过期、错视角、错类别、错 mask、重复 between 实例和未知关系必须拒绝。

指令转弯、后续路径对齐、首次离开必须分属正确事件；被撤销步骤不再作为完成证据。原地正反转在 BEV 中可见，但不能变成成功的方向条件。图像前后观测与执行步不能混用。

通过真实 verifier 消息组装截获检查事件图、候选 crop、BEV 确实发送；保持每次验证原有 API 调用数与总预算。运行原有574项轻量回归及新增必要检查，再冻结代码和输入进行短片段仿真。

逐项报告代码实现、离线证据和真实在线覆盖。冷启动片段不作为完整 episode 成功率；没触发的分支不声称已在线验证。
